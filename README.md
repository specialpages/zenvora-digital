# Zenvora Digital storefront
Responsive purple ebook storefront using plain HTML, CSS, JavaScript, and JSON.

## Publish
1. Keep index.html and ebook.json at repository root.
2. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. Test /assets/theme.css, /assets/app.js, /assets/zenvora-logo.svg, and /ebook.json.

## Add ebooks
Edit ebook.json. Each product supports id, title, category, price (INR), description, coverText, published, and buyUrl. Keep buyUrl as # until checkout is genuinely connected.

## Important
This is a front-end prototype. No payment processing, payment verification, private file storage, automatic PDF delivery, email system, or admin panel is included. Never commit paid PDF files or public download links to a public repository. Add secure backend verification and private file delivery before accepting payments. Review policy and legal requirements before launch.
