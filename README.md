# Zenvora Digital — GitHub Pages conversion

This static build preserves the supplied Shopify theme's CSS, typography, purple glass palette, animation assets, and homepage section structure while replacing Shopify Liquid with HTML and JavaScript suitable for GitHub Pages.

## Add ebooks
Edit `ebook.json`. Each item supports `id`, `title`, `category`, `price`, `description`, `coverText`, `cover`, `published`, `buyUrl`, and `downloadUrl`.

## Important
GitHub Pages is static hosting. Shopify checkout, customer newsletter forms, private digital delivery, and payment verification do not work just by copying a Shopify theme. The site intentionally does not claim payment or instant PDF delivery is active. Integrate a payment provider and a trusted server-side delivery flow before accepting orders.
